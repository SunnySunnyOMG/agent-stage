# Agent Stage

为用户当前的 Harness 搭建一个运行可视化网页。先发现实际可观测的协议，再生成薄适配层；复用随包提供的动画引擎。通用的是事件约定和接入方法，不是声称所有 Agent 都已接通。

## 开始

从当前任务确定是本机实时查看、历史回放，还是远程网页。用户已表达的目标直接沿用，只问会改变接入方式的缺失条件。将本文件所在目录记为 `SKILL_DIR`，所有辅助路径相对于它；不假设固定的安装位置或宿主命令语法。

1. 检查当前工作区和已有配置，保留未提交修改。找当前 Harness 的文档、公开事件接口及用户指定的样本。只检查用户任务关联的来源，不扫描其他聊天、账户或整个日志目录。
2. 输出简短能力表：来源与版本、连接方式、可观察字段、事件关联键、未暴露能力、启动/部署工具。优先采用文档化的 hooks、SDK 回调、事件流、JSONL；MCP 的工具发现本身不等于可订阅全部运行事件。不能接入时说明实际缺口；可交付明确标为 demo 的页面，但不能将其当实时接入验收。
3. 按 [接入指南](references/integration.md) 为当前能力生成最小适配层。用 [事件约定](references/events.md) 输出 JSONL，并写清来源/关联键/字段映射。优先只读旁路，避免为了观察而替换用户现有 Agent 或重新执行有副作用的任务。

## 搭建网页

复用 `assets/viewer/`。默认网页是正交投影的工作室，角色在有对应观测事件时走到各工位并做出动作。选择 **Event graph** 可以查看同一事件约定下的关系图。两种视图都消费 `core.mjs` 的状态。展示层不得启动、排队或批准业务动作。

按[家具映射表](references/events.md#furniture-mapping)给源事件标注意向。新增或更新待办去 To-do 看板，浏览网页去浏览终端，本地资料查询去阅读桌，普通工作回电脑。明确的记忆、验证或待用户事件分别去书架、核验桌和交接台。只有根任务已结束、观测完整且没有活跃工作时，角色才去喝咖啡和休息。视图、素材和回放都随包提供。

Node.js 20+ 可直接运行，无需安装依赖：

```sh
node "$SKILL_DIR/scripts/serve.mjs" --events ./normalized-events.jsonl
```

命令打印本机 URL。读取 `/health` 并从网页或 `/events` 回读一条实际源事件；不要仅凭进程启动就宣布接入完成。服务只绑定 loopback、仅提供读取；不要将其直接作为公网 collector。

只演示动画时明确使用：

```sh
node "$SKILL_DIR/scripts/serve.mjs" --demo
```

没有 Node 时，静态资源仍可由用户环境已有的静态服务器托管；只承诺验证过的模式，不静默安装重型运行环境。

## 展示规则

- 只使用实际暴露的关联关系画父子边。工具并发不等于多个 Agent，未知状态不补成“思考中”。
- `observed`、`reported`、`demo` 保持可见；Agent 口述状态不得升级为外部观测。
- 结束、成功、验收通过、记忆已保存、经验已复用是不同事实。工具执行成功不能自动点亮后几个环节。
- 断流和缺失结束事件保留最后观测状态，标记观测不完整；不能靠超时补成功或失败。现场恢复用当前快照，历史动画只在明确回放模式播放。
- 只传必要标识、状态和经过脱敏的短标签；不把提示词、工具参数、文件正文或凭证送给网页。模板会丢弃额外字段，但标签仍须由适配层审查。

## 导出与部署

```sh
node "$SKILL_DIR/scripts/export.mjs" --out ./agent-stage-web
```

输出自包含静态目录，保留已有目录，支持演示和浏览器本地导入。按 [部署指南](references/deployment.md) 使用当前可用的部署工具。远程静态页不能直接读取用户电脑上的日志；实时远程查看需要单独配置事件桥接和访问控制，不能用演示数据填补。

用户已明确要求发布时继续执行已授权的发布流程；缺少登录或目标信息时，先交付本地页面和可部署目录，准确说明剩余条件。不默认改全局配置、安装 hooks 或公开运行记录。

## 最小验收与交付

用与当前适配相关的一组小案例检查：开始/结束、并发关联、重复/迟到、缺结束/断流、无验收或记忆事件的反例。每项只显示来源支持的状态。导出后从该目录再打开一次，确认资源不依赖本地 Skill 路径。

交付页面 URL、启动/停止方式、能力表和字段映射；分开报告模板演示、本机真实来源、宿主接入和远程部署实际验证到哪一层。可选部署和主题不要求重建完整监控产品。
